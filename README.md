# Claude en clair

Un petit guide en français, sans jargon, pour bien travailler avec Claude quand on est expert de son domaine (statistique, économie, gestion des risques) mais pas informaticien.

**Ouvrir le guide :** https://hichamabd.github.io/ClaudeEnClair/

## Ce qu'il contient

Sept chapitres courts, chacun construit de la même façon : une idée, trois points, trois détails par point, et un prompt prêt à copier dans Claude.

1. L'essentiel
2. Croiser des données
3. Les gros fichiers
4. Les projets au long cours
5. Les compétences (skills)
6. Pages web et outils
7. Vos logiciels (Office, R, SAS)

Un petit lexique explique les mots de Claude. Dans le texte, chaque mot souligné s'explique d'un clic.

## L'installer comme une appli

- **iPhone :** ouvrez le lien dans Safari, touchez Partager, puis « Sur l'écran d'accueil ».
- **Android :** ouvrez le lien dans Chrome, menu ⋮, puis « Ajouter à l'écran d'accueil ».
- **Ordinateur :** le lien suffit. On peut aussi l'ajouter aux favoris.

## Vie privée

Le guide n'enregistre rien et n'envoie rien, sans compte, cookie ni mesure d'audience. Une fois ouvert, il reste lisible hors ligne : le navigateur garde une copie des fichiers du guide, et rien d'autre.

Les boutons « Copier et ouvrir Claude » copient le prompt et ouvrent une nouvelle conversation sur claude.ai. Vous collez, relisez, puis envoyez.

Guide indépendant, sans lien avec Anthropic. Les informations ont été vérifiées en novembre 2026 sur le centre d'aide de Claude.
